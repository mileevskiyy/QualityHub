# Development status

## Implemented in 0.2

- React/TypeScript interface and Node/Express API.
- Versioned case library, archival and immutable execution snapshots.
- Controlled run lifecycle and linked defect tracking.
- Session authentication, invitation-bound registration and project roles.
- Membership administration with last-owner protection.
- PostgreSQL adapter, SQLite local mode and schema migration tracking.
- Custom Playwright reporter with local evidence files and retry-aware ingestion.
- Project-scoped, revocable integration tokens.
- Idempotent import delivery and payload conflict detection.
- Domain/API/PostgreSQL-engine checks, browser workflow and CI configuration.

## Implemented: run comparison

Completed-run comparison with stable test identity, retained definitions/observations, separate definition-change classification, final-attempt duration deltas, read-permission checks, mobile layout and JSON export.

## Next development milestones

1. Result attachments, trace storage and controlled artifact downloads.
2. Saved filters, pagination and indexed query measurements on generated datasets.
3. Flaky-test indicators with documented definitions and a minimum observation window.
4. Email delivery, verified invitations and password recovery.
5. Fine-grained PostgreSQL locking and a dedicated migration runner.
6. Authenticated hosted pilot, backup-restore validation and user feedback.

Future milestones are not represented as completed features or production achievements.
